# Source

A snapshot of the Unity source for this lab, copied from the `Density Lab` Unity project (Unity 6, URP):

- `Assets/PhotoLab/` — scripts, editor scene builder and browser build script, models (spinach, coleus, turtle grass, blue crab, hole punch), generated scene.
- `Assets/WebGLTemplates/PhotoLab/` — the page the build is embedded in.

To rebuild: drop both folders into a Unity project that also has the Density Lab's fume hood scene, Liquid Volume Pro, Volumetric Light Beam and Highlight Plus installed, then run **Photo Lab > Rebuild Scene** and **Photo Lab > Build for the Browser**.

This copy is refreshed by hand; the live build in the repo root is the authority.
